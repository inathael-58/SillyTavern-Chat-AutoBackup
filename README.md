# Chat Auto Backup (SillyTavern Extension)

สำรองแชทอัตโนมัติไว้ใน **เบราว์เซอร์** (IndexedDB) โดยคัดลอกจากแชทที่อยู่ในหน้าจอ ไม่ได้อ่านจากเซิร์ฟเวอร์ แม้เซิร์ฟเวอร์จะบันทึกไม่สำเร็จ ส่งแชทกลับมาไม่ครบ หรือไฟล์หาย ก็ยังมีสำเนาอยู่

## ติดตั้ง

ใน SillyTavern เปิด **Extensions → Install extension** แล้ววาง URL นี้:

```
https://github.com/inathael-58/SillyTavern-Chat-AutoBackup
```

รีเฟรชหน้า แล้วจะเห็นแผง **Chat Auto Backup** ใน Extensions

<details>
<summary>ติดตั้งเองแบบวางไฟล์ (ถ้าเข้าถึงโฟลเดอร์ของเซิร์ฟเวอร์ได้)</summary>

1. ดาวน์โหลด repo นี้เป็น zip แล้วแตกให้ได้โฟลเดอร์ `SillyTavern-Chat-AutoBackup`
2. คัดลอกไปไว้ที่
   - `SillyTavern/public/scripts/extensions/third-party/SillyTavern-Chat-AutoBackup` (ใช้ได้ทุก user) **หรือ**
   - `SillyTavern/data/<ชื่อuser>/extensions/SillyTavern-Chat-AutoBackup` (เฉพาะ user นั้น)
3. รีเฟรชหน้า SillyTavern

</details>

## ทำงานอย่างไร

| จังหวะ | สิ่งที่ extension ทำ |
|---|---|
| ส่ง/รับ/แก้/ลบ/swipe ข้อความ | คัดลอกแชททันที แล้วรอ 4 วินาทีจึงเขียนลงเครื่อง (ถ้ามีหลายเหตุการณ์ติดกันจะรวมเป็นครั้งเดียว) |
| เปลี่ยนแชท | บันทึกของแชทเดิมที่ค้างอยู่ให้เสร็จก่อน แล้วเก็บสำเนาของแชทใหม่ตามที่โหลดมา |
| ทุก 5 นาที | ตรวจว่ามีอะไรเปลี่ยนที่ event ไม่ได้จับไว้หรือไม่ |
| เปิดแชทแล้วจำนวนข้อความ < 60% ของ backup | ขึ้นเตือน **⚠ แชทอาจหาย/ไม่ครบ** คลิกที่ข้อความเตือนเพื่อไปหน้ากู้คืน |

- **ไม่เก็บซ้ำ**: ถ้าแชทไม่เปลี่ยน (เทียบจาก hash) จะไม่สร้าง snapshot ใหม่
- **ไม่เก็บแชทว่าง**: แชทที่ว่างเปล่าอาจเกิดจากตอนที่โหลดล้มเหลว จึงไม่นำมาบันทึก
- **บีบอัดแบบ gzip**: ขนาดไฟล์ลดลงประมาณ 5–10 เท่า
- **เก็บแชทละ 15 snapshot** (ปรับได้) และ **เก็บ snapshot ที่มีข้อความมากที่สุดไว้เสมอ** ถ้าเซิร์ฟเวอร์โหลดแชทมาไม่ครบแล้วคุณคุยต่อไปเรื่อย ๆ snapshot ใหม่ที่ไม่ครบจะไม่ไปแทนฉบับที่สมบูรณ์

## ปุ่มสถานะบนหน้าแชท

ปุ่มลอยบนจอ บอกว่าแชทที่เปิดอยู่ backup ถึงข้อความที่เท่าไหร่แล้ว (นับเลขแบบเดียวกับ SillyTavern ซึ่งเริ่มที่ `#0`)

| ข้อความบนปุ่ม | ความหมาย |
|---|---|
| `OK! #123` | backup ล่าสุดตรงกับแชทบนจอ ครบถึงข้อความ #123 |
| `Waiting... #120` | มีการเปลี่ยนแปลงที่ยังไม่ได้บันทึก เลขคือส่วนที่ backup แล้ว |
| `Attention! #123` | แชทบนจอสั้นกว่า backup มาก (แชทอาจหาย) หรือบันทึก backup ไม่สำเร็จ เลขคือจุดที่ backup มีถึง |

- **แตะ/คลิก** เพื่อเปิดรายการ backup ของแชทนั้น
- **ลาก** ไปวางตรงไหนก็ได้ พอปล่อยปุ่มจะดูดติดขอบจอที่ใกล้ที่สุด จำตำแหน่งไว้ให้ และยังอยู่ในจอเสมอแม้หมุนจอหรือเปลี่ยนขนาดหน้าต่าง
- ถ้าปุ่มหายไปหรือเข้าถึงไม่ได้ ให้กด **รีเซ็ตตำแหน่งปุ่ม** ในแผง Extensions ปุ่มจะกลับมาอยู่กลางจอ
- ตัวอักษรใช้สี `--SmartThemeQuoteColor` ส่วนพื้นหลังใช้ `--SmartThemeBlurTintColor` ที่ความทึบ 50% และทึบเต็มเมื่อวางเมาส์หรือลาก `Waiting...` จะเป็นตัวอักษรจางลง `Attention!` เป็นตัวหนาและมีขอบกระพริบเบา ๆ
- ปรับขนาดตัวอักษร (8–40 px) หรือซ่อนปุ่มได้ในแผง Extensions
- **แตะตอนขึ้น `Attention!` หรือ `DB!`/`✗`** จะเปิดหน้าอธิบายว่าเกิดอะไรขึ้น พร้อมปุ่มทางเลือก:
  - *แชทสั้นกว่า backup*: **โหลดแชทใหม่จากเซิร์ฟเวอร์**, **กู้คืนฉบับ N ข้อความ** (สร้างเป็นไฟล์แชทใหม่), **เลือก backup เอง** หรือ **ตั้งใจลบเอง** (ใช้แชทนี้เป็นฉบับหลักต่อจากนี้ backup เดิมยังอยู่ในรายการ และส่งทับ Dropbox ถ้าเชื่อมต่อไว้)
  - *ยังไม่ได้ส่งขึ้น Dropbox เพราะไฟล์บน Dropbox ใหญ่กว่า*: **ดึงฉบับจาก Dropbox** หรือ **ส่งทับ Dropbox**
  - *ส่งขึ้น Dropbox ไม่สำเร็จ*: บอกข้อความ error และมีปุ่ม **ลองส่งอีกครั้ง**
  - *บันทึกลงเครื่องไม่สำเร็จ*: **ลองบันทึกอีกครั้ง** หรือ **Export backup ทั้งหมด**

## กู้คืน

กด **ดู/กู้คืน** ในแผงตั้งค่า หรือแตะปุ่มสถานะ จะเห็นรายการ snapshot ทั้งหมด แต่ละรายการแสดง:

- เวลา จำนวนข้อความ และป้าย `swipe 2/4` (ข้อความล่าสุดมีหลาย swipe และตอนนั้นเลือกอันไหนอยู่), `สูงสุด` (snapshot ที่ไม่ถูกลบอัตโนมัติ มีอันเดียวต่อแชท), `สั้นลง`
- **สิ่งที่เปลี่ยนจาก snapshot ก่อนหน้า** เช่น `+1 ข้อความ (#20)`, `+1 swipe ที่ #20 (เลือก 3/3)`, `เปลี่ยนไปใช้ swipe 2/3 ที่ #20`, `แก้ #18`, `ลบ 1 ข้อความ (#19)`
- **ข้อความตัวอย่าง** ของข้อความล่าสุด ตัดแท็กออกให้แล้ว: แท็กที่ตั้งชื่อเอง เช่น `<scene>…</scene>`, `<status>…</status>`, `<thinking>…</thinking>`, `<details>`, `<div>` จะถูกตัดทิ้งทั้งก้อน ส่วนแท็กจัดรูปแบบ เช่น `<b>`, `<i>`, `<span>`, `<font>`, `<br>`, `<p>` ตัดแค่ตัวแท็กแต่เก็บข้อความข้างในไว้ ถ้าตัดแล้วไม่เหลืออะไรจะแสดงข้อความข้างในแท็กแทน **แตะข้อความตัวอย่างเพื่ออ่านข้อความล่าสุดแบบเต็ม** แตะอีกครั้งเพื่อย่อ

การตัดแท็กมีผลเฉพาะตอนแสดงในรายการ ไฟล์ที่กู้คืนหรือดาวน์โหลดยังเป็นข้อความดิบครบทุกตัวอักษร

**Swipe:** snapshot เก็บทุก swipe ของทุกข้อความ กู้คืนแล้วข้อความสุดท้ายจะเปิดที่ swipe ที่เลือกไว้ตอนนั้น และปัดดูอันอื่นได้ตามปกติ

**รวม snapshot ที่ต่างกันแค่ swipe** (เปิดไว้เป็นค่าเริ่มต้น): ถ้าเปลี่ยนแค่ swipe ของข้อความสุดท้าย (ปัดหรือสร้าง swipe ใหม่) จะแทนที่ snapshot ล่าสุดแทนการเพิ่มรายการใหม่ ไม่เสียข้อมูลเพราะ snapshot ใหม่มีทุก swipe อยู่แล้ว (ระบบเช็กว่า swipe เดิมอยู่ครบก่อนแทนที่) รายการจะขึ้นว่า `(รวม swipe ไว้ N ครั้ง)` โควตา snapshot ต่อแชทจะไม่หมดไปกับการ swipe ไม่ใช้กับ snapshot ที่กด Backup ตอนนี้ (manual)

- **กู้คืน**: บันทึกเป็นไฟล์แชท **ใหม่** บนเซิร์ฟเวอร์ ชื่อไฟล์ `<ชื่อเดิม> (restored <เวลา>)` โดยไม่เขียนทับไฟล์เดิม ถ้าตอนนั้นเปิดตัวละครนั้นอยู่จะเปิดแชทที่กู้ให้เลย ถ้าไม่ได้เปิดอยู่ให้หาได้ใน *Manage chat files*
- **ดาวน์โหลด**: ได้ไฟล์ `.jsonl` รูปแบบเดียวกับไฟล์แชทของ SillyTavern นำไป *Import chat* ได้
- **แชทกลุ่ม**: ใช้ได้แค่ดาวน์โหลด ให้นำไฟล์ไปวางใน `data/<user>/group chats/` เอง

## สำรองขึ้น Dropbox (อัตโนมัติ)

ส่ง snapshot ล่าสุดของแต่ละแชทขึ้น Dropbox ของคุณเอง ถ้าเครื่องหาย ล้างข้อมูลเว็บไซต์ หรือลบ Web App ออกจากหน้าจอโฮม (ซึ่งจะลบข้อมูลในเครื่องทิ้งทั้งหมด) ก็ยังดึงกลับมาได้

**ตั้งค่าครั้งเดียว**
1. เข้า <https://www.dropbox.com/developers/apps> แล้วกด **Create app** เลือก **Scoped access** และ **App folder** ตั้งชื่ออะไรก็ได้
2. แท็บ **Permissions**: ติ๊ก `files.content.write` และ `files.content.read` แล้วกด **Submit** (ต้องทำก่อนขั้นที่ 4)
3. แท็บ **Settings**: คัดลอก **App key** (ไม่ต้องใช้ App secret และไม่ต้องใส่ Redirect URI)
4. ใน ST แผง Chat Auto Backup → **สำรองขึ้น Dropbox** วาง App key แล้วกด **เชื่อมต่อ** จากนั้นกดลิงก์ **เปิดหน้าอนุญาตของ Dropbox** แล้วกด Allow คัดลอกรหัสที่ Dropbox แสดง กลับมาวาง แล้วกด **ยืนยันรหัส**

การเชื่อมต่อจะค้างไว้ถาวร ไม่ต้องกดอนุญาตซ้ำ ค่าที่ใช้เชื่อมต่อเก็บไว้ใน settings ของ ST บนเซิร์ฟเวอร์ ทุกอุปกรณ์ที่ใช้ user เดียวกันจึงเชื่อมต่อด้วย และสิทธิ์ที่ให้ไปเข้าถึงได้เฉพาะโฟลเดอร์ `Apps/<ชื่อ app>` เท่านั้น

**ทำงานอย่างไร**
- หนึ่งแชทมีหนึ่งไฟล์ ใน `Apps/<ชื่อ app>/character/<avatar>/<ชื่อแชท>.jsonl` เป็นไฟล์แชทของ ST แบบปกติ นำไป *Import chat* ใน ST ได้โดยไม่ต้องใช้ extension นี้
- ส่งเฉพาะแชทที่มี snapshot ใหม่ ส่งทีละแชท ในแรมมีแค่แชทเดียวต่อครั้ง ไม่โหลดข้อมูลทั้งหมดแบบ Pocky
- แต่ละแชทจะส่งไม่ถี่กว่าทุก 2 นาที (ปรับได้) และจะพยายามส่งทันทีเมื่อสลับออกจากแอป
- **กันแชทหายไปทับของดี**: ถ้าแชทในเครื่องสั้นกว่าไฟล์บน Dropbox มาก หรือถูกติดป้าย `สั้นลง` จะไม่ส่ง และขึ้นเหตุผลไว้ในแผงตั้งค่า ถ้าตั้งใจลบข้อความจริง กด **ส่งตอนนี้** แล้วยืนยัน นอกจากนี้ Dropbox ยังเก็บประวัติเวอร์ชันของไฟล์ไว้อีกประมาณ 30 วัน
- ส่งไม่สำเร็จ เช่น เน็ตหลุด จะลองใหม่เอง

**ดูว่าส่งถึงไหนแล้ว**: ถ้าเชื่อมต่อ Dropbox อยู่ ปุ่มสถานะจะมีส่วนต่อท้ายบอกว่าแชทที่เปิดอยู่ส่งขึ้น Dropbox ถึงข้อความที่เท่าไหร่ ปิดส่วนนี้ได้ในแผงตั้งค่า

| ส่วนต่อท้าย | ความหมาย |
|---|---|
| `· DB #20` | Dropbox มี backup ล่าสุดแล้ว ครบถึงข้อความ #20 |
| `· DB #18...` | มี backup ใหม่รอส่งอยู่ ตอนนี้ Dropbox มีถึง #18 (ตัวอักษรจางลง) |
| `· DB! #18` | ไม่ได้ส่ง เพราะแชทดูเหมือนหาย หรือส่งไม่สำเร็จ (ตัวหนา) |

เลือกได้ในแผงตั้งค่า (**สถานะ Dropbox บนปุ่ม**) ว่าจะแสดง **แบบเต็ม** (`DB #20` / `DB #18...` / `DB! #18`) **แบบย่อ** (`✓` / `…` / `✗`) หรือ **ไม่แสดง**

วางเมาส์หรือกดค้างที่ปุ่มเพื่อดูเวลาที่ส่งล่าสุดและเหตุผล ในรายการ backup ทุก snapshot ที่ส่งขึ้นไปแล้วจะมีป้าย `Dropbox`

**ดึงกลับ**: กด **ดึง backup จาก Dropbox** ทุกไฟล์จะกลับมาเป็น snapshot ติดป้าย `จาก Dropbox` แล้วกู้คืนจากรายการ backup ตามปกติ ถ้าแชทที่เปิดอยู่สั้นกว่าไฟล์ที่ดึงมา ปุ่มสถานะจะขึ้น `Attention!`

## ย้ายมาจาก Pocky chat vault

Pocky เก็บ snapshot แบบไม่บีบอัดไว้ในฐานข้อมูลของตัวเองใน browser (`sillytavern-chat-vault`) การถอนการติดตั้ง extension ไม่ได้ลบข้อมูลนี้ออก ถ้าเจอฐานข้อมูลนี้ในแผงตั้งค่าจะมีส่วน **ข้อมูลที่ Pocky chat vault ทิ้งไว้** แสดงขึ้นมา

- **นำเข้าอันที่สำคัญ**: นำ backup ล่าสุดของแต่ละแชท และจุดคืนค่าที่ตั้งชื่อไว้ มาเป็น snapshot ของที่นี่ ติดป้าย `จาก Pocky` จุดคืนค่าที่ตั้งชื่อไว้จะแสดงชื่อเดิม และระบบจะไม่ลบอัตโนมัติ ประวัติอัตโนมัติอื่น ๆ ของ Pocky จะไม่นำเข้า ระบบอ่านทีละรายการเพื่อไม่ให้ Safari หน่วยความจำเต็ม กดซ้ำได้ ข้อมูลจะไม่ซ้ำ
- **ลบฐานข้อมูล Pocky**: ลบข้อมูลของ Pocky ทั้งหมดใน browser นี้เพื่อคืนพื้นที่ ไม่กระทบ backup ของ Chat Auto Backup ควรถอนการติดตั้ง Pocky ก่อน ไม่อย่างนั้นมันจะสร้างข้อมูลใหม่ขึ้นมาอีก

## ข้อควรรู้

- **อัปเดตแล้วแต่หน้าจอยังเป็นตัวเก่า**: ST โหลดไฟล์ extension จาก URL เดิมทุกครั้ง และ Web App บนหน้าจอโฮมของ iPhone แทบไม่โหลดหน้าใหม่จริง ๆ โค้ดเก่าจึงค้างอยู่ได้นาน ตั้งแต่ v1.5.1 เป็นต้นไป เวอร์ชันที่กำลังทำงานจะแสดงอยู่ข้างชื่อในแผงตั้งค่า ถ้าบนเซิร์ฟเวอร์มีเวอร์ชันใหม่กว่า จะขึ้นข้อความ "แตะที่นี่เพื่อโหลดเวอร์ชันใหม่" แตะแล้วระบบจะดึงไฟล์ใหม่มาแทนของที่ค้างอยู่ แล้วโหลดหน้าใหม่ให้

- หน้ารายการ backup ปิดได้ด้วยปุ่ม ✕ คลิกนอกกรอบ หรือกด Esc
- Backup ผูกกับ **เบราว์เซอร์และอุปกรณ์ที่ใช้อยู่** โทรศัพท์กับคอมจะมี backup แยกกัน และการล้างข้อมูลเว็บไซต์ (Clear site data) จะลบ backup ไปด้วย
  → ควรกด **Export** เก็บไฟล์ไว้เป็นระยะ และใช้ **Import** เพื่อย้ายไปเครื่องอื่น
- Extension จะขอสิทธิ์ `persistent storage` จากเบราว์เซอร์ เพื่อกันไม่ให้ข้อมูลถูกลบเองเมื่อพื้นที่ใกล้เต็ม
- เปิดรายการ backup ครั้งแรกหลังอัปเดตเป็น v1.3 จะขึ้น "กำลังเตรียมข้อมูล snapshot เก่า…" สักครู่ เพื่อสร้างข้อความตัวอย่างและข้อมูลการเปลี่ยนแปลงให้ snapshot เดิม ทำครั้งเดียว
- ถ้าเปิดหลายแท็บพร้อมกัน แต่ละแท็บจะ backup ของตัวเอง ใช้งานได้ปกติ แต่อาจมี snapshot มากกว่าที่ตั้งไว้เล็กน้อย
- ใช้ใน DevTools console ได้: `ChatAutoBackup.backupNow()`, `await ChatAutoBackup.dbAllMeta()`
