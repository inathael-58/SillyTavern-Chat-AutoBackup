# Chat Auto Backup (SillyTavern Extension)

สำรองแชทอัตโนมัติไว้ใน **เบราว์เซอร์** (IndexedDB) โดยคัดลอกจากแชทที่อยู่ในหน้าจอ ไม่ได้อ่านจากเซิร์ฟเวอร์ แม้เซิร์ฟเวอร์จะบันทึกไม่สำเร็จ ส่งแชทกลับมาไม่ครบ หรือไฟล์หาย ก็ยังมีสำเนาอยู่

## ติดตั้ง

ใน SillyTavern เปิด **Extensions → Install extension** แล้ววาง URL นี้:

```
https://github.com/inathael-58/SillyTavern-Chat-AutoBackup
```

รีเฟรชหน้า แล้วจะเห็นแผง **Chat Auto Backup** ใน Extensions

<details>
<summary>ติดตั้งเองแบบวางไฟล์ (ถ้าเข้าถึงโฟลเดอร์ของเซิร์ฟเวอร์ได้)</summary>

1. ดาวน์โหลด repo นี้เป็น zip แล้วแตกให้ได้โฟลเดอร์ `SillyTavern-Chat-AutoBackup`
2. คัดลอกไปไว้ที่
   - `SillyTavern/public/scripts/extensions/third-party/SillyTavern-Chat-AutoBackup` (ใช้ได้ทุก user) **หรือ**
   - `SillyTavern/data/<ชื่อuser>/extensions/SillyTavern-Chat-AutoBackup` (เฉพาะ user นั้น)
3. รีเฟรชหน้า SillyTavern

</details>

## ทำงานอย่างไร

| จังหวะ | สิ่งที่ extension ทำ |
|---|---|
| ส่ง/รับ/แก้/ลบ/swipe ข้อความ | คัดลอกแชททันที แล้วรอ 4 วินาทีจึงเขียนลงเครื่อง (ถ้ามีหลายเหตุการณ์ติดกันจะรวมเป็นครั้งเดียว) |
| เปลี่ยนแชท | บันทึกของแชทเดิมที่ค้างอยู่ให้เสร็จก่อน แล้วเก็บสำเนาของแชทใหม่ตามที่โหลดมา |
| ทุก 5 นาที | ตรวจว่ามีอะไรเปลี่ยนที่ event ไม่ได้จับไว้หรือไม่ |
| เปิดแชทแล้วจำนวนข้อความ < 60% ของ backup | ขึ้นเตือน **⚠ แชทอาจหาย/ไม่ครบ** คลิกที่ข้อความเตือนเพื่อไปหน้ากู้คืน |

- **ไม่เก็บซ้ำ**: ถ้าแชทไม่เปลี่ยน (เทียบจาก hash) จะไม่สร้าง snapshot ใหม่
- **ไม่เก็บแชทว่าง**: แชทที่ว่างเปล่าอาจเกิดจากตอนที่โหลดล้มเหลว จึงไม่นำมาบันทึก
- **ไม่เก็บแชทที่มีแค่ข้อความทักทาย**: กด New Chat แล้วยังไม่ได้พิมพ์อะไร (มีแค่ first message หรือข้อความทักทายของสมาชิกแต่ละตัวในแชทกลุ่ม) จะยังไม่ backup และไม่ส่งขึ้น Dropbox เริ่มเก็บเมื่อส่งข้อความแรก ยกเว้นแชทที่สร้างด้วย **เริ่มแชทใหม่ต่อเรื่อง** ของ Memory Hub ซึ่งพกความจำมาด้วย จะ backup ทันที แชทที่เคยมี backup แล้วจะยังเก็บต่อตามปกติ แม้ลบข้อความจนเหลือแค่ข้อความทักทาย
- **บีบอัดแบบ gzip**: ขนาดไฟล์ลดลงประมาณ 5–10 เท่า
- **เก็บแชทละ 15 snapshot** (ปรับได้) และ **เก็บ snapshot ที่มีข้อความมากที่สุดไว้เสมอ** ถ้าเซิร์ฟเวอร์โหลดแชทมาไม่ครบแล้วคุณคุยต่อไปเรื่อย ๆ snapshot ใหม่ที่ไม่ครบจะไม่ไปแทนฉบับที่สมบูรณ์

## ปุ่มสถานะบนหน้าแชท

ปุ่มลอยบนจอ บอกว่าแชทที่เปิดอยู่ backup ถึงข้อความที่เท่าไหร่แล้ว (นับเลขแบบเดียวกับ SillyTavern ซึ่งเริ่มที่ `#0`)

| ข้อความบนปุ่ม | ความหมาย |
|---|---|
| `OK! #123` | backup ล่าสุดตรงกับแชทบนจอ ครบถึงข้อความ #123 |
| `Waiting... #120` | มีการเปลี่ยนแปลงที่ยังไม่ได้บันทึก เลขคือส่วนที่ backup แล้ว |
| `Attention! #123` | แชทบนจอสั้นกว่า backup มาก (แชทอาจหาย) หรือบันทึก backup ไม่สำเร็จ เลขคือจุดที่ backup มีถึง |
| `New` (ขอบเส้นประ) | แชทใหม่ที่มีแค่ข้อความทักทาย ยังไม่ backup จะเริ่มเมื่อส่งข้อความแรก |

- **แตะ/คลิก** เพื่อเปิดรายการ backup ของแชทนั้น
- **ลาก** ไปวางตรงไหนก็ได้ พอปล่อยปุ่มจะดูดติดขอบจอที่ใกล้ที่สุด จำตำแหน่งไว้ให้ และยังอยู่ในจอเสมอแม้หมุนจอหรือเปลี่ยนขนาดหน้าต่าง
- ถ้าปุ่มหายไปหรือเข้าถึงไม่ได้ ให้กด **รีเซ็ตตำแหน่งปุ่ม** ในแผง Extensions ปุ่มจะกลับมาอยู่กลางจอ
- ตัวอักษรใช้สี `--SmartThemeQuoteColor` ส่วนพื้นหลังใช้ `--SmartThemeBlurTintColor` ที่ความทึบ 50% และทึบเต็มเมื่อวางเมาส์หรือลาก `Waiting...` จะเป็นตัวอักษรจางลง `Attention!` เป็นตัวหนาและมีขอบกระพริบเบา ๆ
- ปรับขนาดตัวอักษร (8–40 px) หรือซ่อนปุ่มได้ในแผง Extensions
- **แตะตอนขึ้น `Attention!` หรือ `DB!`/`✗`** จะเปิดหน้าอธิบายว่าเกิดอะไรขึ้น พร้อมปุ่มทางเลือก:
  - *แชทสั้นกว่า backup*: **โหลดแชทใหม่จากเซิร์ฟเวอร์**, **กู้คืนฉบับ N ข้อความ** (สร้างเป็นไฟล์แชทใหม่), **เลือก backup เอง** หรือ **ตั้งใจลบเอง** (ใช้แชทนี้เป็นฉบับหลักต่อจากนี้ backup เดิมยังอยู่ในรายการ และส่งทับ Dropbox ถ้าเชื่อมต่อไว้)
  - *ยังไม่ได้ส่งขึ้น Dropbox เพราะไฟล์บน Dropbox ใหญ่กว่า*: **ดึงฉบับจาก Dropbox** หรือ **ส่งทับ Dropbox**
  - *แชทนี้ถูกแก้จากอีกเครื่อง*: **ซิงค์แชทนี้** (ดูหัวข้อซิงค์แชทระหว่างเครื่อง)
  - *ส่งขึ้น Dropbox ไม่สำเร็จ*: บอกข้อความ error และมีปุ่ม **ลองส่งอีกครั้ง**
  - *บันทึกลงเครื่องไม่สำเร็จ*: **ลองบันทึกอีกครั้ง** หรือ **Export backup ทั้งหมด**

## กู้คืน

กด **ดู/กู้คืน** ในแผงตั้งค่า หรือแตะปุ่มสถานะ จะเห็นรายการ snapshot ทั้งหมด แต่ละรายการแสดง:

- เวลา จำนวนข้อความ และป้าย `swipe 2/4` (ข้อความล่าสุดมีหลาย swipe และตอนนั้นเลือกอันไหนอยู่), `สูงสุด` (snapshot ที่ไม่ถูกลบอัตโนมัติ มีอันเดียวต่อแชท), `สั้นลง`
- **สิ่งที่เปลี่ยนจาก snapshot ก่อนหน้า** เช่น `+1 ข้อความ (#20)`, `+1 swipe ที่ #20 (เลือก 3/3)`, `เปลี่ยนไปใช้ swipe 2/3 ที่ #20`, `แก้ #18`, `ลบ 1 ข้อความ (#19)`
- **ข้อความตัวอย่าง** ของข้อความล่าสุด ตัดแท็กออกให้แล้ว: แท็กที่ตั้งชื่อเอง เช่น `<scene>…</scene>`, `<status>…</status>`, `<thinking>…</thinking>`, `<details>`, `<div>` จะถูกตัดทิ้งทั้งก้อน ส่วนแท็กจัดรูปแบบ เช่น `<b>`, `<i>`, `<span>`, `<font>`, `<br>`, `<p>` ตัดแค่ตัวแท็กแต่เก็บข้อความข้างในไว้ ถ้าตัดแล้วไม่เหลืออะไรจะแสดงข้อความข้างในแท็กแทน **แตะข้อความตัวอย่างเพื่ออ่านข้อความล่าสุดแบบเต็ม** แตะอีกครั้งเพื่อย่อ

การตัดแท็กมีผลเฉพาะตอนแสดงในรายการ ไฟล์ที่กู้คืนหรือดาวน์โหลดยังเป็นข้อความดิบครบทุกตัวอักษร

**Swipe:** snapshot เก็บทุก swipe ของทุกข้อความ กู้คืนแล้วข้อความสุดท้ายจะเปิดที่ swipe ที่เลือกไว้ตอนนั้น และปัดดูอันอื่นได้ตามปกติ

**รวม snapshot ที่ต่างกันแค่ swipe** (เปิดไว้เป็นค่าเริ่มต้น): ถ้าเปลี่ยนแค่ swipe ของข้อความสุดท้าย (ปัดหรือสร้าง swipe ใหม่) จะแทนที่ snapshot ล่าสุดแทนการเพิ่มรายการใหม่ ไม่เสียข้อมูลเพราะ snapshot ใหม่มีทุก swipe อยู่แล้ว (ระบบเช็กว่า swipe เดิมอยู่ครบก่อนแทนที่) รายการจะขึ้นว่า `(รวม swipe ไว้ N ครั้ง)` โควตา snapshot ต่อแชทจะไม่หมดไปกับการ swipe ไม่ใช้กับ snapshot ที่กด Backup ตอนนี้ (manual)

- **กู้คืน**: บันทึกเป็นไฟล์แชท **ใหม่** บนเซิร์ฟเวอร์ ชื่อไฟล์ `<ชื่อเดิม> (restored <เวลา>)` โดยไม่เขียนทับไฟล์เดิม ถ้าตอนนั้นเปิดตัวละครนั้นอยู่จะเปิดแชทที่กู้ให้เลย ถ้าไม่ได้เปิดอยู่ให้หาได้ใน *Manage chat files*
- **ดาวน์โหลด**: ได้ไฟล์ `.jsonl` รูปแบบเดียวกับไฟล์แชทของ SillyTavern นำไป *Import chat* ได้
- **แชทกลุ่ม**: ใช้ได้แค่ดาวน์โหลด ให้นำไฟล์ไปวางใน `data/<user>/group chats/` เอง

## สำรองขึ้น Dropbox (อัตโนมัติ)

ส่ง snapshot ล่าสุดของแต่ละแชทขึ้น Dropbox ของคุณเอง ถ้าเครื่องหาย ล้างข้อมูลเว็บไซต์ หรือลบ Web App ออกจากหน้าจอโฮม (ซึ่งจะลบข้อมูลในเครื่องทิ้งทั้งหมด) ก็ยังดึงกลับมาได้

**ตั้งค่าครั้งเดียว**
1. เข้า <https://www.dropbox.com/developers/apps> แล้วกด **Create app** เลือก **Scoped access** และ **App folder** ตั้งชื่ออะไรก็ได้
2. แท็บ **Permissions**: ติ๊ก `files.content.write` และ `files.content.read` แล้วกด **Submit** (ต้องทำก่อนขั้นที่ 4)
3. แท็บ **Settings**: คัดลอก **App key** (ไม่ต้องใช้ App secret และไม่ต้องใส่ Redirect URI)
4. ใน ST แผง Chat Auto Backup → **สำรองขึ้น Dropbox** วาง App key แล้วกด **เชื่อมต่อ** จากนั้นกดลิงก์ **เปิดหน้าอนุญาตของ Dropbox** แล้วกด Allow คัดลอกรหัสที่ Dropbox แสดง กลับมาวาง แล้วกด **ยืนยันรหัส**

การเชื่อมต่อจะค้างไว้ถาวร ไม่ต้องกดอนุญาตซ้ำ ค่าที่ใช้เชื่อมต่อเก็บไว้ใน settings ของ ST บนเซิร์ฟเวอร์ ทุกอุปกรณ์ที่ใช้ user เดียวกันจึงเชื่อมต่อด้วย และสิทธิ์ที่ให้ไปเข้าถึงได้เฉพาะโฟลเดอร์ `Apps/<ชื่อ app>` เท่านั้น

**ทำงานอย่างไร**
- หนึ่งแชทมีหนึ่งไฟล์ ใน `Apps/<ชื่อ app>/character/<avatar>/<ชื่อแชท>.jsonl` เป็นไฟล์แชทของ ST แบบปกติ นำไป *Import chat* ใน ST ได้โดยไม่ต้องใช้ extension นี้
- ส่งเฉพาะแชทที่มี snapshot ใหม่ ส่งทีละแชท ในแรมมีแค่แชทเดียวต่อครั้ง ไม่โหลดข้อมูลทั้งหมดแบบ Pocky
- แต่ละแชทจะส่งไม่ถี่กว่าทุก 2 นาที (ปรับได้) และจะพยายามส่งทันทีเมื่อสลับออกจากแอป
- **กันแชทหายไปทับของดี**: ถ้าแชทในเครื่องสั้นกว่าไฟล์บน Dropbox มาก หรือถูกติดป้าย `สั้นลง` จะไม่ส่ง และขึ้นเหตุผลไว้ในแผงตั้งค่า ถ้าตั้งใจลบข้อความจริง กด **ส่งตอนนี้** แล้วยืนยัน นอกจากนี้ Dropbox ยังเก็บประวัติเวอร์ชันของไฟล์ไว้อีกประมาณ 30 วัน
- ส่งไม่สำเร็จ เช่น เน็ตหลุด จะลองใหม่เอง

**ดูว่าส่งถึงไหนแล้ว**: ถ้าเชื่อมต่อ Dropbox อยู่ ปุ่มสถานะจะมีส่วนต่อท้ายบอกว่าแชทที่เปิดอยู่ส่งขึ้น Dropbox ถึงข้อความที่เท่าไหร่ ปิดส่วนนี้ได้ในแผงตั้งค่า

| ส่วนต่อท้าย | ความหมาย |
|---|---|
| `· DB #20` | Dropbox มี backup ล่าสุดแล้ว ครบถึงข้อความ #20 |
| `· DB #18...` | มี backup ใหม่รอส่งอยู่ ตอนนี้ Dropbox มีถึง #18 (ตัวอักษรจางลง) |
| `· DB! #18` | ไม่ได้ส่ง เพราะแชทดูเหมือนหาย หรือส่งไม่สำเร็จ (ตัวหนา) |

เลือกได้ในแผงตั้งค่า (**สถานะ Dropbox บนปุ่ม**) ว่าจะแสดง **แบบเต็ม** (`DB #20` / `DB #18...` / `DB! #18`) **แบบย่อ** (`✓` / `…` / `✗`) หรือ **ไม่แสดง**

วางเมาส์หรือกดค้างที่ปุ่มเพื่อดูเวลาที่ส่งล่าสุดและเหตุผล ในรายการ backup ทุก snapshot ที่ส่งขึ้นไปแล้วจะมีป้าย `Dropbox`

**ดึงกลับ**: กด **ดึง backup จาก Dropbox** ทุกไฟล์จะกลับมาเป็น snapshot ติดป้าย `จาก Dropbox` แล้วกู้คืนจากรายการ backup ตามปกติ ถ้าแชทที่เปิดอยู่สั้นกว่าไฟล์ที่ดึงมา ปุ่มสถานะจะขึ้น `Attention!`

## ซิงค์แชทระหว่างเครื่อง (เช่น ST บนโฮส ↔ TauriTavern)

ถ้าเล่นสลับหลายที่ ให้ติดตั้ง extension นี้ทุกที่ แล้วเชื่อมต่อ **Dropbox app เดียวกัน** (ใช้ App key เดียวกัน) แชทที่คุยต่อจากที่หนึ่งจะถูกเขียนลงแชทของอีกที่ให้ ไม่ต้องขอไฟล์ backup จากแอดมินของโฮส

**เปิดใช้**: แผง Chat Auto Backup → **ซิงค์แชทระหว่างเครื่อง** ติ๊ก **ดึงแชทที่ใหม่กว่าจาก Dropbox อัตโนมัติ** หรือกด **ซิงค์ตอนนี้** เองก็ได้

**ซิงค์เมื่อไหร่**: ซิงค์เต็ม (เทียบทุกแชท preset การ์ด ฯลฯ) เฉพาะตอนเปิดแอป และเมื่อมีการเปลี่ยนแปลงจริง
- อีกเครื่องเขียนอะไรลง Dropbox: เครื่องนี้เช็คเบา ๆ ทุก 1 นาทีและทุกครั้งที่กลับเข้าแอป (ขอ Dropbox แค่ "มีไฟล์ไหนเปลี่ยนบ้าง" ครั้งเดียว ไม่สแกนอะไรในเครื่อง) เจอการเปลี่ยนแปลงจากอีกเครื่องเมื่อไหร่ถึงซิงค์เต็ม ไฟล์ที่เครื่องนี้ส่งขึ้นเองไม่นับ
- แก้ preset การ์ด lorebook persona Quick Reply หรือ regex ในเครื่องนี้: ซิงค์ประมาณ 10 วินาทีหลังบันทึกครั้งสุดท้าย
- การ์ดใหม่ที่เพิ่มในเครื่องนี้ (สร้าง นำเข้า หรือ extension อื่นเพิ่มให้) จะถูกเจอภายในรอบเช็คถัดไปเสมอ ใช้ได้กับ ST บนโฮสที่เป็นเวอร์ชันเก่าด้วย
- ถ้าการ์ดหลายใบส่ง/รับไม่ทันในรอบเดียว (ทำทีละประมาณ 15 วินาที) รอบเช็คถัดไปจะทำต่อเอง โดยทำการ์ดที่เพิ่มใหม่หรือเปลี่ยนจากอีกเครื่องก่อน แล้วค่อยตรวจการ์ดที่ตรงกันอยู่แล้ว แชทของการ์ดใหม่จะตามมาเมื่อการ์ดมาถึง
- การ์ดที่มีแชทรออยู่ใน Dropbox แต่ยังไม่มีในเครื่องนี้ จะถูกดึงก่อนอย่างอื่น แชทของมันจึงตามมาในรอบเดียวกัน ถ้าการ์ดเคยซิงค์แล้วแต่หายไปจากเครื่องนี้โดยไม่ได้ลบหรือเปลี่ยนชื่อเอง (เช่น นำเข้าไม่ติด) จะนำเข้าให้ใหม่ ถ้านำเข้าแล้วยังไม่ขึ้นในรายการตัวละคร จะขึ้นเป็น error ในแผงตั้งค่า
- ถ้าแผงตั้งค่าขึ้นว่า **ข้าม N แชทเพราะไม่มีตัวละคร…** ระบบจะบอกต่อว่าการ์ดอยู่ใน Dropbox แล้ว (รอรอบถัดไป) หรือยังไม่มีใน Dropbox (ต้องไปกด **ซิงค์ตอนนี้** ที่เครื่องที่มีการ์ด)
- แชทที่ข้ามเพราะตัวละครไม่มีทั้งในเครื่องนี้และใน Dropbox (เช่น ลบตัวละครไปแล้ว แต่แชทยังค้างใน Dropbox) จะมีปุ่ม **ลบแชทที่ข้ามออกจาก Dropbox (N)** กดแล้วยืนยัน แชทจะถูกลบจาก Dropbox และเครื่องอื่นลบตาม (Dropbox เก็บไว้ให้กู้ได้ประมาณ 30 วัน)
- แชทที่คุยในเครื่องนี้ส่งขึ้นทันทีเหมือนเดิม (ไม่ต้องรอซิงค์เต็ม)
- เปิดจอค้างไว้เฉย ๆ ถ้าไม่มีอะไรเปลี่ยนจะไม่ซิงค์และไม่ขึ้นสัญลักษณ์
- ซิงค์อัตโนมัติตรวจเฉพาะประเภทที่เปลี่ยน (เช่น แก้ lorebook ก็ตรวจแค่ lorebook) ไม่อ่าน preset การ์ด lorebook ทั้งหมดใหม่ทุกรอบ และตรวจครบทุกประเภทอย่างน้อยทุก 30 นาที ส่วนปุ่ม **ซิงค์ตอนนี้** ตรวจครบทุกประเภทเสมอ
- เปิดแชทเก่า หรือ extension เขียนข้อมูลลงการ์ด จะซิงค์ก็ต่อเมื่อเนื้อหาการ์ดเปลี่ยนจริง (ST บันทึกการ์ดซ้ำทุกครั้งที่เปิดแชท เพื่อจำว่าเปิดแชทไหนล่าสุด)

เมื่อเปิดไว้ แชทที่เปลี่ยนในเครื่องนี้จะ **ส่งขึ้น Dropbox ทันที** ประมาณ 5 วินาทีหลังข้อความเสร็จ (ไม่รอรอบ "ส่งแต่ละแชทไม่ถี่กว่าทุก … นาที") ถ้าปิดแท็บบนคอมตอนที่ยังส่งไม่เสร็จ เบราว์เซอร์จะถามก่อนปิด บนมือถือการสลับออกจากแอปจะเริ่มส่งให้ทันที

**สัญลักษณ์สถานะซิงค์** (ด้านบนกลางจอ ขึ้นทุกหน้า ไม่ต้องเปิดแชท): ตอนเปิดแอปหรือกลับเข้าแอป ให้รอจนขึ้น ✓ ก่อนค่อยเปิดแชท

| สัญลักษณ์ | ความหมาย |
|---|---|
| ◌ หมุน **รอตรวจเช็คข้อมูลกับ Dropbox…** | เพิ่งเปิด/กลับเข้าแอป จะเริ่มตรวจในอีกไม่กี่วินาที (ถ้ากำลังส่งแชทขึ้น Dropbox อยู่ จะรอแค่แชทที่กำลังส่งอยู่ แชทที่เหลือส่งต่อหลังซิงค์ ถ้า Dropbox ไม่ตอบนานเกิน 1–3 นาที จะเลิกรอแล้วลองใหม่รอบหน้า) |
| ◌ หมุน **กำลังตรวจเช็คข้อมูล… (แชท 3/12)** | กำลังเทียบกับ Dropbox ยังไม่ได้เขียนอะไร |
| ◌ หมุน **กำลังซิงค์…** + ชื่อ | กำลังเขียนแชท/preset/การ์ด… จากอีกเครื่องลงเครื่องนี้ |
| ✓ **ซิงค์เรียบร้อย** (· อัปเดต N รายการ / ไม่มีอะไรเปลี่ยน) | เสร็จแล้ว เปิดแชทได้ หายไปเองในไม่กี่วินาที |
| ⚠ **รอเลือก N รายการ** | ค้างไว้จนกว่าจะเลือก แตะเพื่อเปิดหน้าเลือกฉบับ |
| ✗ **ซิงค์ไม่สำเร็จ** | แตะเพื่อดูสาเหตุและลองใหม่ |

ตอนกลับเข้าแอปถ้าไม่มีอะไรเปลี่ยน จะขึ้นแค่แป๊บเดียว การซิงค์ที่เกิดเองระหว่างใช้งาน (อีกเครื่องเปลี่ยนอะไร หรือแก้ preset ฯลฯ ในเครื่องนี้) จะขึ้นสัญลักษณ์เฉพาะตอนกำลังเขียนอะไรลงเครื่องนี้ ปิดได้ที่ **แสดงสัญลักษณ์สถานะซิงค์ด้านบนจอ** ขนาดตัวอักษรตามค่า **ขนาดตัวอักษรปุ่ม**

**ระบบตัดสินใจให้อย่างไร** (เทียบข้อความ และ chat metadata ที่ extension เก็บไว้ในแชท เช่น ความจำของ Memory Hub, ตัวแปร `{{getvar}}` ของ preset, author's note)

| สถานการณ์ | สิ่งที่เกิดขึ้น |
|---|---|
| อีกเครื่องคุยต่อ / swipe เพิ่ม และเครื่องนี้ไม่ได้แตะ | เขียนลงแชทในเครื่องนี้เลย ถ้าเปิดแชทนั้นอยู่จะโหลดใหม่ให้ |
| อีกเครื่องแก้หรือลบข้อความ และเครื่องนี้ไม่ได้แตะตั้งแต่ซิงค์ครั้งล่าสุด | เขียนลงเครื่องนี้เลย (ถ้าลบไปเกิน 40% จะถามก่อน) |
| เครื่องนี้คุยต่อ อีกเครื่องไม่ได้แตะ | ส่งขึ้น Dropbox ตามปกติ |
| ข้อความเหมือนกัน ต่างแค่ chat metadata (เช่น Memory Hub สรุปเพิ่มหลังตอบ) | ใช้ของ Dropbox ถ้าเครื่องนี้ไม่ได้แก้ ถ้าแก้ทั้งสองฝั่ง รวมกัน (key ที่มีฝั่งเดียวเก็บไว้ key ที่มีทั้งคู่ใช้ของ Dropbox) |
| แก้ทั้งสองฝั่งก่อนจะซิงค์ | **ไม่ทับอะไรเอง** ขึ้นให้เลือก: **ใช้ฉบับ Dropbox** / **ใช้ฉบับในเครื่อง** / **เก็บทั้งคู่** (ฉบับ Dropbox กลายเป็นไฟล์แชทใหม่) |
| แชทใหม่จากอีกเครื่อง (สร้างหลังเริ่มใช้การซิงค์ที่นี่) | สร้างในเครื่องนี้ให้เลย |
| แชทบน Dropbox ที่มีมาก่อนเริ่มซิงค์ที่นี่ หรือแชทที่ลบไปแล้วในเครื่องนี้ | ไม่สร้างเอง ขึ้นให้เลือก **สร้าง** / **ลบทุกเครื่อง** / **ข้าม** มีปุ่มทำทีเดียวทั้งหมดถ้ามีหลายแชท |
| เปลี่ยนชื่อแชทใน ST เครื่องนี้ (หรือใน Chat Browser) | snapshot ในเครื่องย้ายไปชื่อใหม่ ไฟล์ใน Dropbox ย้ายไปชื่อใหม่ อีกเครื่องลบชื่อเดิมและสร้างชื่อใหม่ให้ตอนซิงค์ (ถ้าแชทชื่อเดิมที่นั่นมีข้อความที่ยังไม่ได้ซิงค์ จะถามก่อนลบ) |
| ลบแชทใน ST เครื่องนี้ | ลบไฟล์ใน Dropbox ด้วย แล้วอีกเครื่องลบตามตอนซิงค์ ถ้าอีกเครื่องแก้แชทนั้นหลังซิงค์ครั้งล่าสุด (หรือเปิดอยู่) จะถามก่อน: **ลบในเครื่องนี้ด้วย** / **เก็บไว้** (ส่งกลับขึ้น Dropbox แล้วเครื่องที่ลบไปจะได้คืน) ปิดได้ที่ **ลบแชทแล้วลบใน Dropbox และเครื่องอื่นด้วย** |

- ก่อนเขียนทับแชทในเครื่อง ฉบับเดิมจะถูกเก็บในรายการ backup ติดป้าย `ก่อนซิงค์` ฉบับที่ได้มาติดป้าย `ซิงค์จาก Dropbox` ก่อนลบตามอีกเครื่อง เก็บไว้ติดป้าย `ก่อนลบ` และ Dropbox เก็บไฟล์ที่ลบไว้ให้กู้ได้อีกประมาณ 30 วัน
- การลบส่งต่อผ่านไฟล์เล็ก ๆ ในโฟลเดอร์ `deleted/` ของ app ใน Dropbox ใช้เฉพาะเครื่องที่เคยซิงค์แล้ว ถ้าใช้ Dropbox เป็น backup อย่างเดียว (ไม่เคยกดซิงค์) การลบแชทจะไม่ลบ backup ใน Dropbox
- การส่งขึ้น Dropbox จะ **ไม่ทับไฟล์ที่อีกเครื่องเพิ่งแก้** ถ้าเจอแบบนี้ปุ่มสถานะจะขึ้น `DB!` แตะแล้วกด **ซิงค์แชทนี้**
- แชทที่ต้องเลือกจะขึ้น ⚠ ที่สัญลักษณ์สถานะซิงค์ (หรือแจ้งเตือน ถ้าปิดสัญลักษณ์ไว้) แตะเพื่อเปิดหน้าเลือก หรือกดปุ่ม **เลือกฉบับ** ในแผงตั้งค่า
- เปิดแท็บอื่นค้างไว้ที่แชทเดียวกันบนเซิร์ฟเวอร์เดียวกัน: แท็บนั้นจะบันทึกทับไม่ได้ (ST ขึ้นเตือน integrity ให้โหลดหน้าใหม่) กันฉบับที่ซิงค์มาหาย
- ใช้กับ TauriTavern ที่เปิด "Load historical swipes on demand" ได้ ระบบจะอ่านแชทฉบับเต็มจากเซิร์ฟเวอร์ก่อนส่งขึ้น ไม่ทำให้ swipe เก่าหาย

### Clean Sync (ผ่าน Chat Browser)

ทำให้ Dropbox และทุกเครื่องมีแชทเหมือนเครื่องนี้เป๊ะ ใช้รายชื่อแชทในเครื่องนี้เป็นหลัก กดได้จากปุ่ม **Clean Sync** ใน [Chat Browser](https://github.com/inathael-58/SillyTavern-Chat-Browser)

1. ส่งแชทที่ค้างขึ้น Dropbox แล้วซิงค์ตามปกติหนึ่งรอบก่อน แชทที่อีกเครื่องเพิ่งสร้างจะถูกดึงมา ไม่ถูกลบ
2. แสดงรายการที่จะทำให้ดูก่อน ยังไม่ลบอะไร เอาเครื่องหมายออกจากแชทที่อยากเก็บไว้ได้
   - แชทที่มีใน Dropbox แต่ไม่มีในเครื่องนี้ (รวมแชทของตัวละครที่ไม่มีในเครื่องนี้) → ลบออกจาก Dropbox และทิ้งเครื่องหมายไว้ให้เครื่องอื่นลบตาม
   - แชทที่เครื่องอื่นลบไปแล้ว แต่เครื่องนี้ยังมี → เก็บไว้ ส่งกลับขึ้น Dropbox
   - แชทในเครื่องนี้ที่ยังไม่เคยขึ้น Dropbox → ส่งขึ้นไป (ยกเว้นแชทที่มีแค่ข้อความทักทาย)
3. กดยืนยันแล้วจึงลบ จากนั้นแสดงรายชื่อที่ลบไป พร้อมปุ่ม **กู้คืน**

- เครื่องอื่นลบตามตอนซิงค์ครั้งถัดไป โดยไม่ถาม ถ้าแชทที่นั่นตรงกับฉบับที่ถูกลบ ถ้าที่นั่นมีข้อความที่ยังไม่ได้ซิงค์ หรือเปิดแชทนั้นอยู่ จะถามก่อน
- **กู้คืน**: เครื่องที่กด Clean Sync จำรายการที่ลบไว้ (ประวัติ Clean Sync ในหน้าเดียวกัน) กดกู้คืนแล้วไฟล์กลับมาใน Dropbox สร้างแชทกลับมาในเครื่องนี้ และเครื่องอื่นได้คืนตอนซิงค์ ใช้ได้ตราบที่ Dropbox ยังเก็บไฟล์ที่ลบไว้ (ประมาณ 30 วันสำหรับบัญชีทั่วไป)
- Clean Sync จัดการแค่ว่ามีแชทไหนบ้าง แชทที่แก้ทั้งสองฝั่งยังต้องเลือกฉบับเองเหมือนเดิม และไม่แตะ preset การ์ด lorebook persona Quick Reply regex หรือ Connection profile
- แชทที่อยู่ในอีกเครื่องแต่ไม่เคยขึ้น Dropbox เลย Clean Sync มองไม่เห็น จึงลบให้ไม่ได้
- ใช้ได้เมื่อเปิดซิงค์ระหว่างเครื่องแล้ว (กดซิงค์อย่างน้อยหนึ่งครั้ง)

### preset, การ์ดตัวละคร, lorebook, persona, Quick Reply, regex และ Connection profile

ติ๊ก **ซิงค์ preset ด้วย**, **ซิงค์ lorebook ด้วย**, **ซิงค์ persona ด้วย**, **ซิงค์ Quick Reply ด้วย**, **ซิงค์ regex ด้วย**, **ซิงค์ Connection profile ด้วย** และ **ซิงค์การ์ดตัวละครด้วย** (เปิดไว้เป็นค่าเริ่มต้นทั้งหมด) แล้วจะซิงค์พร้อมแชททุกรอบ

- **preset**: ทุกประเภทที่ ST จัดการ ได้แก่ Chat Completion, Text Completion, KoboldAI, NovelAI และ Advanced Formatting (Instruct, Context, System Prompt, Reasoning) เก็บใน Dropbox ที่ `presets/<ประเภท>/<ชื่อ>.json`
  - ถ้า preset ที่เลือกใช้อยู่ถูกอัปเดตจากอีกเครื่อง จะโหลดค่าใหม่ให้ทันที ค่าที่ปรับไว้แต่ยังไม่ได้กด Update preset จะถูกแทน
- **การ์ด**: ไฟล์ PNG แบบเดียวกับ Export PNG (ข้อมูลการ์ด รูป lorebook ที่ฝังในการ์ด) เก็บที่ `cards/<ชื่อไฟล์>.png`
  - ใช้ชื่อไฟล์ avatar เดียวกันทุกเครื่อง แชทของการ์ดจึงตามไปด้วย การ์ดใหม่จากอีกเครื่องจะถูกสร้างก่อน แล้วแชทของมันจะซิงค์ตามมา
  - การ์ดที่อัปเดตมาจากอีกเครื่องยังเก็บแชทล่าสุดที่เปิดและสถานะ favorite ของเครื่องนี้ไว้
- **lorebook**: lorebook (World Info) ที่เป็นไฟล์แยก เก็บที่ `worlds/<ชื่อ>.json` ถ้าเปิด lorebook นั้นค้างไว้ในหน้าแก้ จะโหลดฉบับใหม่ให้ lorebook ใหม่จากอีกเครื่องจะขึ้นในรายการทันที
- **persona**: ชื่อ คำอธิบาย ตำแหน่ง/ความลึก lorebook ที่ผูกไว้ การผูกกับตัวละคร และรูป เก็บที่ `personas/<ชื่อไฟล์รูป>.json` ถ้าแก้ persona ที่ใช้อยู่ จะอัปเดตคำอธิบายของ persona ปัจจุบันให้ด้วย
  - ถ้าเปลี่ยนแค่รูป รูปจะตามไปพร้อมการแก้ชื่อหรือคำอธิบายครั้งถัดไป
- **Quick Reply**: ทุกชุด เก็บที่ `quickreplies/<ชื่อชุด>.json` ชุดที่อัปเดตจากอีกเครื่องจะใช้ได้หลัง **โหลดหน้าใหม่** (ขึ้นแจ้งเตือนให้แตะ) ระหว่างรอโหลดหน้าใหม่ Quick Reply จะหยุดซิงค์ชั่วคราว กันไม่ให้ฉบับเก่าในหน่วยความจำถูกส่งกลับไปทับ
- **regex**: regex แบบ global ทีละสคริปต์ เก็บที่ `regex/<id>.json` ใช้ได้ทันที **ลำดับ** ของสคริปต์ (ลำดับที่ทำงาน) ซิงค์ด้วย ถ้าจัดลำดับใหม่ทั้งสองฝั่งพร้อมกัน ใช้ลำดับจาก Dropbox regex ที่ผูกกับการ์ดหรือ preset ไปพร้อมการ์ด/preset อยู่แล้ว
- **Connection profile**: ทุก profile ของ Connection Manager (API, Server URL, model, preset/template ที่ผูกไว้ ฯลฯ) เก็บที่ `connprofiles/<id>.json` จับคู่ด้วย id ภายใน เปลี่ยนชื่อจึงเป็นแค่การแก้
  - **ไม่ส่ง API key**: ส่งไปแค่ชนิดของ key (เช่น `api_key_makersuite`) และชื่อที่ตั้งให้ key ไม่ส่งตัว key
  - profile ที่มาจากอีกเครื่องซึ่งผูก API key ไว้ จะขึ้นหน้าต่าง **ใส่ API key ให้ Connection profile** หลังซิงค์ ให้วาง key สำหรับเครื่องนี้ หรือเลือก key ชนิดเดียวกันที่มีในเครื่องนี้อยู่แล้ว หรือกด **ข้าม** เพื่อใช้ key ปัจจุบันของเครื่องนี้ ปิดหน้าต่างไปก่อนก็ได้ จะมีปุ่ม **ใส่ API key ให้ profile (N)** ในแผงซิงค์ให้กลับมาทำต่อ
  - profile ที่เคยผูก key ไว้ในเครื่องนี้แล้ว ยังใช้ key เดิมเสมอ ไม่ถามซ้ำ
  - ถ้า profile ที่เลือกใช้อยู่ถูกอัปเดตจากอีกเครื่อง ค่าใหม่มีผลเมื่อเลือก profile นั้นอีกครั้ง
  - ลบ profile ที่เครื่องหนึ่ง อีกเครื่องลบตามตอนซิงค์ (ถ้าเครื่องนั้นแก้ไว้ จะถามก่อน)
  - **profile ชื่อซ้ำ** (สร้างแยกกันในแต่ละเครื่องก่อนเปิดซิงค์ เลยมีทั้งสองอันในทุกเครื่อง): ถ้าตั้งค่าเหมือนกัน รวมเหลืออันเดียวให้เอง (ทุกเครื่องเลือกอันเดียวกัน profile ที่ใช้อยู่และ API key ที่ผูกไว้ย้ายตามไป) ถ้าตั้งค่าต่างกัน มีปุ่ม **Connection profile ชื่อซ้ำ (N)** ให้เลือกว่าจะเก็บอันไหน อันที่เหลือถูกลบทุกเครื่อง
  - profile ที่ไม่ต้องการ (เช่น ตัวเก่าที่ลบไปแล้วในเครื่องหนึ่งแต่กลับมาจากอีกเครื่อง) ลบใน Connection Manager ของเครื่องไหนก็ได้ แล้วอีกเครื่องจะลบตามตอนซิงค์
- **ลบ / เปลี่ยนชื่อ Quick Reply, regex, การ์ด และ persona**: ลบที่เครื่องหนึ่ง อีกเครื่องลบตามตอนซิงค์ (ถ้าเครื่องนั้นแก้ไว้หลังซิงค์ครั้งล่าสุด จะถามก่อน: **ลบในเครื่องนี้ด้วย** / **เก็บไว้**) เปลี่ยนชื่อชุด Quick Reply = สร้างชุดชื่อใหม่ + ลบชุดเดิม จึงตามไปทั้งสองอย่าง regex จับคู่ด้วย id ภายใน เปลี่ยนชื่อสคริปต์จึงเป็นแค่การแก้ ปิดการลบตามได้ที่ **ลบแล้วลบใน Dropbox และเครื่องอื่นด้วย**
  - การ์ดที่ถูกลบจากอีกเครื่อง: ลบแค่ตัวการ์ด ไฟล์แชทยังอยู่บนเซิร์ฟเวอร์ (แชทที่ถูกลบด้วยจะลบตามแยกกันอยู่แล้ว) ถ้านำเข้าการ์ดชื่อไฟล์เดิมกลับมา แชทก็กลับมาด้วย
  - การ์ดและ persona ที่ถูกลบที่อีกเครื่อง **จะไม่ถูกลบในเครื่องนี้เองเลย** จะขึ้นให้เลือก **ลบในเครื่องนี้ด้วย** / **เก็บไว้** ทุกครั้ง (มีปุ่มเลือกทีเดียวทั้งหมดเมื่อมีหลายรายการ)
  - ลบทีละหลายตัว (เช่นด้วย Bulk Manager) ระหว่างที่กำลังส่งข้อมูลอยู่ จะซิงค์การลบให้หลังส่งเสร็จ ไม่ดึงตัวที่ลบกลับมา
  - ส่งการลบต่อเฉพาะการ์ดหรือ persona ที่กดลบเองในเครื่องนี้ การ์ดที่แค่หายไปจากรายการ (เช่น เปลี่ยนชื่อตัวละคร ซึ่ง ST จะเปลี่ยนชื่อไฟล์ตามไปด้วย) จะไม่ไปลบที่เครื่องอื่น
  - **กู้การ์ด/persona ที่ถูกลบ** (ปุ่มข้าง ซิงค์ตอนนี้) แสดงการ์ดและ persona ที่ถูกลบผ่านการซิงค์ เลือกแล้วกด กู้คืน ไฟล์เดิมใน Dropbox จะถูกกู้ แล้วกลับเข้าทุกเครื่อง แชทที่ยังอยู่ในเครื่องจะกลับมาพร้อมการ์ด Dropbox เก็บไฟล์ที่ลบไว้ประมาณ 30 วัน
- ตัดสินแบบเดียวกับแชท: ฝั่งเดียวแก้ ใช้ของฝั่งนั้นเลย แก้ทั้งสองฝั่ง (หรือเริ่มซิงค์ครั้งแรกแล้วสองฝั่งไม่ตรงกัน) ขึ้นให้เลือก **ใช้ฉบับ Dropbox** / **ใช้ฉบับในเครื่อง** / **เก็บทั้งคู่** (เฉพาะ preset: ฉบับ Dropbox ถูกบันทึกเป็น `<ชื่อ> (Dropbox)`)
- preset ที่ไม่ใช่ preset จริง (เช่น ไฟล์ regex pack ที่ถูกนำเข้าเป็น preset) จะไม่ถูกส่งขึ้น ถ้ามีไฟล์แบบนี้อยู่ใน Dropbox แล้ว เครื่องอื่นจะข้ามไฟล์นั้น และบอกไว้ในแผงตั้งค่า (ไม่ขึ้นว่าซิงค์ไม่สำเร็จ)
- ค่าที่ ST เติมให้เองตอนบันทึกซ้ำ (เช่น ช่องว่าง หรือ `false` ใน lorebook ของการ์ด) ไม่นับเป็นการแก้
- ครั้งแรกจะส่ง preset และการ์ดทุกอันขึ้น Dropbox การ์ดที่มีรูปใหญ่อาจใช้เน็ตพอสมควร ในการซิงค์อัตโนมัติจะทำทีละประมาณ 15 วินาทีต่อรอบ ถ้าอยากให้จบในครั้งเดียวกด **ซิงค์ตอนนี้**
- การลบหรือเปลี่ยนชื่อ preset และ lorebook ยังไม่ซิงค์ (เปลี่ยนชื่อ = ได้อันใหม่ อันเดิมยังอยู่)

**ข้อจำกัดตอนนี้**
- ไม่ซิงค์ theme (ตั้งใจ: TauriTavern แสดงผล theme ที่ใช้ CSS บางแบบต่างจาก ST) และ settings อื่น ๆ เช่น การตั้งค่า API ที่ยังไม่ได้บันทึกเป็น Connection profile, sampler ที่ยังไม่ได้บันทึกเป็น preset และ API key
- กลุ่มต้องมีอยู่แล้วทั้งสองที่ (จับคู่ด้วย id) แชทของตัวละครหรือกลุ่มที่ไม่มีในเครื่องนี้จะถูกข้าม แผงตั้งค่าบอกไว้ว่าข้ามอะไรบ้าง
- ซิงค์ทำงานตอนที่เปิดหน้า ST อยู่เท่านั้น ปุ่มสถานะขึ้น `DB #…` ที่ไม่มี `...` แปลว่าส่งครบแล้ว ปิดได้เลย ถ้าบนมือถือปิดแอปทันทีหลังข้อความเสร็จ (ภายในไม่กี่วินาที) ข้อความล่าสุดอาจยังไม่ขึ้น — เครื่องนั้นจะส่งต่อเองตอนเปิดครั้งหน้า และถ้าอีกเครื่องแก้แชทเดียวกันไปก่อน จะขึ้นให้เลือกฉบับ ไม่ทับกัน
- chat metadata ที่เปลี่ยนโดยไม่มีข้อความใหม่ (เช่น Memory Hub สรุปเสร็จทีหลัง) จะถูกส่งขึ้นตอนสลับออกจากแอป หรือรอบตรวจทุก 5 นาที
- **Prompt Itemization ไม่ซิงค์**: ST เก็บไว้ในเบราว์เซอร์ของเครื่องที่สร้างข้อความ ข้อความที่สร้างจากอีกเครื่องจึงไม่มีปุ่มดู prompt
- ตัวเลข token ในหน้า preset ของสองแอปอาจไม่เท่ากันแม้แชทเดียวกัน เพราะแต่ละแอปใช้ตัวนับ token ต่างกัน
- ลบตัวละครหรือกลุ่มทั้งตัว: แชทของตัวนั้นยังค้างใน Dropbox ให้กด **ลบแชทที่ข้ามออกจาก Dropbox** ที่เครื่องอื่น (หรือใช้ Clean Sync)

## ย้ายมาจาก Pocky chat vault

Pocky เก็บ snapshot แบบไม่บีบอัดไว้ในฐานข้อมูลของตัวเองใน browser (`sillytavern-chat-vault`) การถอนการติดตั้ง extension ไม่ได้ลบข้อมูลนี้ออก ถ้าเจอฐานข้อมูลนี้ในแผงตั้งค่าจะมีส่วน **ข้อมูลที่ Pocky chat vault ทิ้งไว้** แสดงขึ้นมา

- **นำเข้าอันที่สำคัญ**: นำ backup ล่าสุดของแต่ละแชท และจุดคืนค่าที่ตั้งชื่อไว้ มาเป็น snapshot ของที่นี่ ติดป้าย `จาก Pocky` จุดคืนค่าที่ตั้งชื่อไว้จะแสดงชื่อเดิม และระบบจะไม่ลบอัตโนมัติ ประวัติอัตโนมัติอื่น ๆ ของ Pocky จะไม่นำเข้า ระบบอ่านทีละรายการเพื่อไม่ให้ Safari หน่วยความจำเต็ม กดซ้ำได้ ข้อมูลจะไม่ซ้ำ
- **ลบฐานข้อมูล Pocky**: ลบข้อมูลของ Pocky ทั้งหมดใน browser นี้เพื่อคืนพื้นที่ ไม่กระทบ backup ของ Chat Auto Backup ควรถอนการติดตั้ง Pocky ก่อน ไม่อย่างนั้นมันจะสร้างข้อมูลใหม่ขึ้นมาอีก

## ข้อควรรู้

- **อัปเดตแล้วแต่หน้าจอยังเป็นตัวเก่า**: ST โหลดไฟล์ extension จาก URL เดิมทุกครั้ง และ Web App บนหน้าจอโฮมของ iPhone แทบไม่โหลดหน้าใหม่จริง ๆ โค้ดเก่าจึงค้างอยู่ได้นาน ตั้งแต่ v1.5.1 เป็นต้นไป เวอร์ชันที่กำลังทำงานจะแสดงอยู่ข้างชื่อในแผงตั้งค่า ถ้าบนเซิร์ฟเวอร์มีเวอร์ชันใหม่กว่า จะขึ้นข้อความ "แตะที่นี่เพื่อโหลดเวอร์ชันใหม่" แตะแล้วระบบจะดึงไฟล์ใหม่มาแทนของที่ค้างอยู่ แล้วโหลดหน้าใหม่ให้

- หน้ารายการ backup ปิดได้ด้วยปุ่ม ✕ คลิกนอกกรอบ หรือกด Esc
- Backup ผูกกับ **เบราว์เซอร์และอุปกรณ์ที่ใช้อยู่** โทรศัพท์กับคอมจะมี backup แยกกัน และการล้างข้อมูลเว็บไซต์ (Clear site data) จะลบ backup ไปด้วย
  → ควรกด **Export** เก็บไฟล์ไว้เป็นระยะ และใช้ **Import** เพื่อย้ายไปเครื่องอื่น
- Extension จะขอสิทธิ์ `persistent storage` จากเบราว์เซอร์ เพื่อกันไม่ให้ข้อมูลถูกลบเองเมื่อพื้นที่ใกล้เต็ม
- เปิดรายการ backup ครั้งแรกหลังอัปเดตเป็น v1.3 จะขึ้น "กำลังเตรียมข้อมูล snapshot เก่า…" สักครู่ เพื่อสร้างข้อความตัวอย่างและข้อมูลการเปลี่ยนแปลงให้ snapshot เดิม ทำครั้งเดียว
- ถ้าเปิดหลายแท็บพร้อมกัน แต่ละแท็บจะ backup ของตัวเอง ใช้งานได้ปกติ แต่อาจมี snapshot มากกว่าที่ตั้งไว้เล็กน้อย
- ใช้ใน DevTools console ได้: `ChatAutoBackup.backupNow()`, `await ChatAutoBackup.dbAllMeta()`
- [Chat Browser](https://github.com/inathael-58/SillyTavern-Chat-Browser) ใช้ `ChatAutoBackup` สำหรับปุ่ม Sync, Clean Sync, สถานะ Dropbox ของแต่ละแชท และการเปลี่ยนชื่อแชท
